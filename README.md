# Single-Page CV

A clean, semantic HTML-based curriculum vitae showcasing my career history, skills, and experience as a Full Stack Developer.

## 🔗 Live URL

**https://cv.dharmendraprajapati.in**

## 📋 Project Overview

This project is a single-page HTML CV created with a focus on:
- Semantic HTML structure
- SEO optimization with meta tags
- Open Graph tags for social media sharing
- Accessibility best practices
- Clean, professional layout

## 🎯 Features

- ✅ **Semantic HTML** - Proper use of HTML5 semantic elements
- ✅ **SEO Optimized** - Complete meta tags for search engines
- ✅ **Social Media Ready** - Open Graph and Twitter Card tags
- ✅ **Favicon** - Multiple sizes for all devices
- ✅ **Structured Data** - JSON-LD schema for better SEO
- ✅ **Mobile Responsive** - Viewport configuration for all devices
- ✅ **Fast Loading** - Optimized static HTML

## 🛠️ Technologies Used

- HTML5
- Semantic HTML elements
- SEO meta tags
- Open Graph Protocol
- JSON-LD structured data
